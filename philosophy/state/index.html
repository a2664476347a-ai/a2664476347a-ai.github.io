道德与政治权力（Morality and Political Power）

在本部分，我们将讨论国家和法律。

在政治哲学中，一个核心问题是：

在没有国家与法律的情况下，道德是否仍然存在？

围绕这一问题，我们需要回答三个更基础的疑问：

  • 人类的本性是什么？
  • 为什么需要国家与法律？
  • 道德义务从何而来？

本文将围绕霍布斯、麦考利与卢梭的理论展开分析。

霍布斯：从恐惧到道德

这一话题源于霍布斯的著作《利维坦》，文中他把利维坦描述为一种不可知的怪物，人人都会害怕它。

我们需要理解以下几个概念，以理解为什么霍布斯会把利维坦类比到国家和法律。

（一）自然状态（State of Nature）

霍布斯认为的自然状态：

  • 资源有限 → 导致竞争
  • 无法律、无权威

因此产生：

  • 冲突与不信任
  • “所有人对所有人的战争”

最终结果：

  • 没有社会、文化、合作
  • 持续的恐惧
  • 随时面临暴力死亡

（二）人性假设

霍布斯认为：

  • 人是自利的（self-interest）
  • 目标是自身的生存与幸福（well-being）

（三）国家的产生

霍布斯的核心逻辑：

人是自利且理性的 ，所以人一定会为了让自己活下去付出一切，所以人们会一直为资源而战。

人们为了避免死亡的危险，愿意：

  • 放弃部分自由
  • 接受国家权威（Leviathan）

国家通过：

  • 法律
  • 惩罚机制

来维持秩序。

（四）道德的来源

霍布斯的关键结论：

道德不是天生的，而是契约的产物

换句话说：

  • 道德依赖国家存在
  • 道德义务是条件性的

即：

只有当他人也遵守规则时，你才有理由遵守

问题

麦考利和卢梭并不赞同霍布斯的想法。

Macaulay

（一）核心矛盾

霍布斯同时主张：

  • 人是自利的 → 不适合社会
  • 人是理性的 → 理性会导出道德

矛盾在于：

如果人人都有理性 → 人人都有道德理由 → 人其实是适合社会的

（二）自然状态的问题

如果：

  • 理性必然导出道德

那么：

自然状态中“没有道德的人类”在概念上是不可能的

（三）社会化与道德起源

Macaulay提出另一种解释路径：

  • 人从婴儿时期开始：
    • 依赖他人
    • 与照料者建立情感联系

发展过程：

自利 → 依赖 → 情感 → 合作 → 道德

关键结论：

道德的基础不是恐惧，而是情感（尤其是爱）

卢梭：自然的善与文明的堕落

（一）方法论批评

卢梭认为：

  • 霍布斯的自然状态其实是：

    “现代人减去法律”

因此是不真实的。

（二）真正的自然状态

卢梭的自然状态具有以下特征：

  • 个体孤立
  • 生活简单
  • 需求极少
  • 无私有财产
  • 无复杂理性
  • 和平、健康

结论：

自然状态是良好的

（三）为什么没有道德问题？

原因有二：

1. 没有理性 → 不会作恶
  • 人不会进行复杂计算
  • 因此也不会有“恶意行为”
2. 没有依赖关系
  • 不需要争夺资源
  • 没有冲突动机

（四）道德的真正来源

卢梭提出：

道德源于“怜悯（pity）”

表现为：

  • 不忍看到他人受苦
  • 自然的同情心

重要观点：

理性越强 → 同情越弱 → 道德可能下降

（五）为何进入社会？

人类并非主动选择离开自然状态，而是由于：

  • 自由意志
  • 可完善性（perfectibility）

发展路径：

  • 环境变化 → 合作
  • 语言发展
  • 农业与分工出现
  • 私有财产产生

随之而来：

  • 比较与竞争
  • 自爱增强
  • 同情减弱
  • 冲突增加

（六）国家的真正作用

卢梭认为：

国家不是为了解决自然状态的问题 而是为了解决文明社会的问题

总结

（一）两种道德模型

霍布斯：

道德 = 自利 + 恐惧 + 国家强制

卢梭：

道德 = 同情 + 人性

（二）根本分歧

两者的核心争论在于：

  • 人是否天生适合社会？
  • 道德是外在强制，还是内在情感？

（三）最终结论

  • 霍布斯：

    没有国家 → 没有道德

  • 卢梭：

    没有社会 → 人反而更接近道德

延伸思考

这一争论揭示了政治哲学中的一个深层问题：

我们之所以遵守道德，是因为害怕惩罚，还是因为关心他人？

不同答案，将导向完全不同的社会与政治理论。
