Inner product spaces

definition

Inner product（内积）

内积是一个函数：[ \langle a, b\rangle:V\times V\to\mathbb F ]其中 (\mathbb F) 通常是 (\mathbb R) 或 (\mathbb C)。

它需要满足教材规定的内积公理，包括正定性、加法性、数乘性质和共轭对称性。

Norm（范数）

向量 (v) 的范数定义为：[ |v|=\sqrt{\langle v,v\rangle} ]

范数表示向量的长度。

Orthogonal vectors（正交向量）

如果[ \langle u,v\rangle=0 ]

就称 (u) 与 (v) 正交，记作 (u\perp v)。

Theorem

Theorem 6.6 — Basic properties of an inner product

设 (V) 是一个内积空间，则：

(a) 对固定的 (v\in V)，映射 (u\mapsto\langle u,v\rangle) 是线性映射。

(b) (\langle 0,v\rangle=0)。

(c) (\langle v,0\rangle=0)。

(d) (\langle u,v+w\rangle=\langle u,v\rangle+\langle u,w\rangle)。

(e) (\langle u,\lambda v\rangle=\overline{\lambda}\langle u,v\rangle)。

Theorem 6.9 — Basic properties of the norm

对任意 (v\in V)：

(a) (|v|=0\iff v=0)。

(b) (|\lambda v|=|\lambda||v|)。

Theorem 6.11 — Orthogonality and 0

(a) 零向量与 (V) 中每一个向量都正交。

(b) 零向量是唯一与自身正交的向量。

Theorem 6.12 — Pythagorean theorem

若 (u,v\in V) 且 (u\perp v)，那么

[ \boxed{|u+v|^2=|u|^2+|v|^2} ]

proof：

[ \begin{aligned} |u+v|^2 &=\langle u+v,u+v\rangle\ &=|u|^2+\langle u,v\rangle\ &\quad+\langle v,u\rangle+|v|^2\ &=|u|^2+0 +0+|v|^2\&=|u|^2+|v|^2. \end{aligned} ]

Theorem 6.13 — An orthogonal decomposition

设 (u,v\in V)，且 (v\ne 0)。定义 [ c=\frac{\langle u,v\rangle}{|v|^2} ]

以及 [ w=u-\frac{\langle u,v\rangle}{|v|^2}v. ]

那么

[ \boxed{u=cv+w,\qquad w\perp v} ]

如下图所示：

proof：

根据定义，

[ w=u-\frac{\langle u,v\rangle}{|v|^2}v. ]

对 (w) 与 (v) 求内积：

[ \begin{aligned} \langle w,v\rangle &=\left\langle u-\frac{\langle u,v\rangle}{|v|^2}v,v \right\rangle\ &=\langle u,v\rangle -\frac{\langle u,v\rangle}{|v|^2} \langle v,v\rangle\ &=\langle u,v\rangle-\langle u,v\rangle\ &=0. \end{aligned} ]

因此 (w\perp v)。同时，根据 (w) 的定义，

[ u=\frac{\langle u,v\rangle}{|v|^2}v+w=cv+w. ]

Theorem 6.14（定理陈述）

对任意内积空间中的向量 (u,v)，都有

[ \boxed{|\langle u,v\rangle| \leq |u||v|} ]

这就是 Cauchy–Schwarz inequality。

proof：

Step 1：先做正交分解。

假设 (v\ne 0)。根据 Theorem 6.13，存在标量 (c) 和向量 (w)，使得

[ u=cv+w,\qquad w\perp v, ]

其中

[ c=\frac{\langle u,v\rangle}{|v|^2}. ]

Step 2：计算内积。

因为 (w\perp v)，所以

[ \begin{aligned} \langle u,v\rangle &=\langle cv+w,v\rangle\ &=c\langle v,v\rangle+\langle w,v\rangle\ &=c|v|^2. \end{aligned} ]

因此

[ |\langle u,v\rangle|=|c||v|^2. ]

Step 3：利用勾股定理。

因为 (cv\perp w)，根据 Theorem 6.12，

[ |u|^2=|cv|^2+|w|^2. ]

又因为 (|cv|=|c||v|)，所以

[ |u|^2 =|c|^2|v|^2+|w|^2 \geq |c|^2|v|^2. ]

开平方后得到

[ |u|\geq |c||v|. ]

两边乘以 (|v|)，就有

[ |u||v|\geq |c||v|^2 =|\langle u,v\rangle|. ]

因此，

[ \boxed{|\langle u,v\rangle|\leq|u||v|}. ]

如果 (v=0)，不等式两边均为零，结论同样成立。

Theorem 6.17 — Triangle inequality（三角不等式）

对任意 (u,v\in V)，都有

[ \boxed{|u+v|\leq|u|+|v|}. ]

等号成立，当且仅当其中一个向量是另一个向量的非负实数倍。

proof:

[ \begin{aligned} |u+v|^2 &=\langle u+v,u+v\rangle\ &=|u|^2+\langle u,v\rangle +\langle v,u\rangle+|v|^2\ &=|u|^2+|v|^2 +2\operatorname{Re}\langle u,v\rangle. \end{aligned} ]

这里 (\operatorname{Re}) 表示复数的实部；如果向量空间定义在 (\mathbb R) 上，就直接取普通实数内积。

由于

[ \operatorname{Re}\langle u,v\rangle \leq|\langle u,v\rangle|, ]

再利用 Theorem 6.14 的柯西–施瓦茨不等式：

[ |\langle u,v\rangle| \leq|u||v|, ]

我们得到

[ \begin{aligned} |u+v|^2 &\leq|u|^2+2|u||v|+|v|^2\ &=(|u|+|v|)^2. \end{aligned} ]

两边均非负，因此开平方：

[ \boxed{|u+v|\leq|u|+|v|}. ]

Orthonormal Bases

definition

Definition 6.22 — Orthonormal list

设 (e_1,\ldots,e_m) 是内积空间 (V) 中的一个向量组。如果它满足以下条件：

[ \boxed{\langle e_j,e_k\rangle= \begin{cases} 1,&j=k,\ 0,&j\ne k, \end{cases}} ]

那么称 (e_1,\ldots,e_m) 是一个 orthonormal list。

Definition 6.27 — Orthonormal basis

如果一个向量组既是 orthonormal list，又是空间 (V) 的一组 basis（基），那么它就是 orthonormal basis（标准正交基）。

theorem

Theorem 6.24 — Norm of an orthonormal linear combination

如果 (e_1,\ldots,e_m) 是 orthonormal list，那么对任意标量 (a_1,\ldots,a_m)，都有

[ \boxed{ \left|\sum_{k=1}^{m}a_ke_k\right|^2 =\sum_{k=1}^{m}|a_k|^2 } ]

proof:

根据范数的定义，

[ \left|\sum_{j=1}^{m}a_je_j\right|^2 = \left\langle \sum_{j=1}^{m}a_je_j, \sum_{k=1}^{m}a_ke_k \right\rangle. ]

利用内积的加法性和数乘性质，可以展开为

[ \sum_{j=1}^{m}\sum_{k=1}^{m} a_j\overline{a_k}\langle e_j,e_k\rangle. ]

由于 (e_1,\ldots,e_m) 是 orthonormal list：

  • 当 (j\ne k) 时，(\langle e_j,e_k\rangle=0)；
  • 当 (j=k) 时，(\langle e_j,e_j\rangle=1)。

所以所有交叉项都消失，只剩下

[ \sum_{j=1}^{m}a_j\overline{a_j} =\sum_{j=1}^{m}|a_j|^2. ]

Theorem 6.25 — Orthonormal lists are linearly independent

每一个 orthonormal list 都是 **linearly independent（线性无关）**的。

proof:

假设

[ a_1e_1+\cdots+a_me_m=0. ]

根据 Theorem 6.24，

[ \left|a_1e_1+\cdots+a_me_m\right|^2 =\sum_{k=1}^{m}|a_k|^2. ]

左边是零向量的范数平方，因此

[ 0=\sum_{k=1}^{m}|a_k|^2. ]

每一项 (|a_k|^2) 都是非负实数。它们的和为零，只能说明每一项都为零：

[ |a_k|^2=0\quad\Longrightarrow\quad a_k=0. ]

因此所有系数都为零，向量组线性无关。

Theorem 6.28 — Orthonormal lists of the right length are orthonormal bases

设 (V) 是有限维向量空间。如果 (e_1,\ldots,e_m) 是一个 orthonormal list，并且

[ m=\dim V, ]

那么 (e_1,\ldots,e_m) 是 (V) 的 orthonormal basis。

proof:

根据 Theorem 6.25，(e_1,\ldots,e_m) 线性无关。

已知 (m=\dim V)。

有限维向量空间中，包含 (\dim V) 个向量的线性无关向量组是基。

因此这组向量是 orthonormal basis。

Theorem 6.26 — Bessel’s inequality（贝塞尔不等式）

设 (e_1,\ldots,e_m) 是内积空间 (V) 中的 orthonormal list。那么对任意 (v\in V)，

[ \boxed{ \sum_{k=1}^{m}|\langle v,e_k\rangle|^2 \leq |v|^2 } ]

proof:

定义

[ p=\sum_{k=1}^{m}\langle v,e_k\rangle e_k. ]

先证明 (v-p) 与每个 (e_j) 都正交。

因为 (e_1,\ldots,e_m) 是 orthonormal list，

[ \begin{aligned} \langle v-p,e_j\rangle &=\langle v,e_j\rangle -\sum_{k=1}^{m}\langle v,e_k\rangle \langle e_k,e_j\rangle\ &=\langle v,e_j\rangle-\langle v,e_j\rangle\ &=0. \end{aligned} ]

因此 (v-p\perp p)。利用勾股定理：

[ |v|^2=|p|^2+|v-p|^2. ]

由于 (|v-p|^2\geq0)，可得

[ |p|^2\leq|v|^2. ]

再根据 Theorem 6.24，

[ |p|^2 =\sum_{k=1}^{m}|\langle v,e_k\rangle|^2. ]

所以

[ \boxed{ \sum_{k=1}^{m}|\langle v,e_k\rangle|^2 \leq|v|^2 }. ]

Theorem 6.30 — Writing a vector as a linear combination of an orthonormal basis

设 (e_1,\ldots,e_n) 是有限维内积空间 (V) 的 orthonormal basis。对任意 (u,v\in V)，有以下三个结论。

(a) 向量展开

[ \boxed{ v=\sum_{k=1}^{n}\langle v,e_k\rangle e_k } ]

也就是说，(v) 在 (e_k) 方向上的系数就是 (\langle v,e_k\rangle)。

(b) Parseval’s identity（帕塞瓦尔恒等式）

[ \boxed{ |v|^2=\sum_{k=1}^{n}|\langle v,e_k\rangle|^2 } ]

这与 Bessel’s inequality 的区别是：这里必须使用完整的 orthonormal basis，而且得到的是等式。

(c) 内积展开

在 Axler 使用的内积约定下，内积对第一个位置线性，因此

[ \boxed{ \langle u,v\rangle =\sum_{k=1}^{n} \langle u,e_k\rangle, \overline{\langle v,e_k\rangle} } ]

如果空间定义在实数域 (\mathbb R) 上，共轭符号可以省略。

proof:

对于 (a)，因为 (e_1,\ldots,e_n) 是基，所以存在系数 (a_1,\ldots,a_n)，使得

[ v=\sum_{k=1}^{n}a_ke_k. ]

两边与 (e_j) 取内积：

[ \langle v,e_j\rangle =\sum_{k=1}^{n}a_k\langle e_k,e_j\rangle =a_j. ]

因此 (a_j=\langle v,e_j\rangle)，从而得到 (a)。

对于 (b)，把 (a) 代入 Theorem 6.24：

[ |v|^2=\sum_{k=1}^{n}|\langle v,e_k\rangle|^2. ]

对于 (c)，将 (a) 的展开式代入 (\langle u,v\rangle)，并利用内积的线性与共轭线性性质，即可得到结论。

Theorem 6.32 — Gram–Schmidt procedure（格拉姆–施密特正交化过程）

设 (v_1,\ldots,v_m) 是有限维内积空间 (V) 中的线性无关向量组。

先定义

[ f_1=v_1, ]

之后对 (k=2,\ldots,m)，定义

[ \boxed{ f_k=v_k-\sum_{j=1}^{k-1} \frac{\langle v_k,f_j\rangle}{|f_j|^2}f_j } ]

再令

[ \boxed{e_k=\frac{f_k}{|f_k|}} \qquad (k=1,\ldots,m). ]

那么：

  1. (e_1,\ldots,e_m) 是 orthonormal list。
  2. 对每个 (k=1,\ldots,m)，都有

[ \boxed{ \operatorname{span}(v_1,\ldots,v_k) =\operatorname{span}(e_1,\ldots,e_k) } ]

也就是说，每一步构造出的向量组都保持相同的 span（张成空间）。

注意：原向量组必须线性无关，这保证了每个 (f_k\ne0)，所以归一化时分母不会为零。

proof：

第一，证明正交性。

根据构造公式，

[ f_k=v_k-\sum_{j=1}^{k-1} \frac{\langle v_k,f_j\rangle}{|f_j|^2}f_j. ]

对于任意 (i<k)，计算 (\langle f_k,f_i\rangle)。由于前面构造的 (f_1,\ldots,f_{k-1}) 两两正交，展开后只剩下

[ \langle f_k,f_i\rangle =\langle v_k,f_i\rangle -\frac{\langle v_k,f_i\rangle}{|f_i|^2} \langle f_i,f_i\rangle =0. ]

因此，所有 (f_k) 两两正交。归一化不会改变正交关系，所以 (e_1,\ldots,e_m) 是 orthonormal list。

第二，证明 span 不变。

由公式可知，(f_k) 是 (v_k) 与前面向量的线性组合，所以

[ f_k\in\operatorname{span}(v_1,\ldots,v_k). ]

反过来，将构造公式整理为

[ v_k=f_k+\sum_{j=1}^{k-1} \frac{\langle v_k,f_j\rangle}{|f_j|^2}f_j. ]

因此，(v_k) 也属于 (\operatorname{span}(f_1,\ldots,f_k))。两边的 span 相同。

最后，(e_j=f_j/|f_j|) 只是将非零向量缩放，所以不会改变 span。因此

[ \operatorname{span}(v_1,\ldots,v_k) =\operatorname{span}(e_1,\ldots,e_k). ]

Theorem 6.37 — Upper-triangular matrix with respect to some orthonormal basis

设 (V) 是有限维内积空间，(T\in\mathcal L(V))。那么，(T) 相对于某一组 orthonormal basis 的矩阵是上三角矩阵，当且仅当 (T) 的最小多项式可以写成

[ \boxed{ m_T(z)=(z-\lambda_1)\cdots(z-\lambda_m) } ]

其中 (\lambda_1,\ldots,\lambda_m\in\mathbb F)，每个因子都是一次因子。

Theorem 6.38 — Schur’s theorem（舒尔定理）

每一个有限维复内积空间上的线性算子，都可以在某一组标准正交基下表示为上三角矩阵。

换句话说，如果 (V) 是有限维复内积空间，并且

[ T\in\mathcal L(V), ]

那么存在 (V) 的一组 orthonormal basis，使得 (T) 相对于该基的矩阵是上三角矩阵。

Theorem 6.42 — Riesz representation theorem（里斯表示定理）

设 (V) 是有限维内积空间，(\varphi) 是 (V) 上的线性泛函。那么存在唯一的向量 (v\in V)，使得对所有 (u\in V)，

[ \boxed{\varphi(u)=\langle u,v\rangle}. ]

proof：

设 (e_1,\ldots,e_n) 是 (V) 的一组 orthonormal basis。

根据 Theorem 6.30，每个 (u\in V) 都可以写成

[ u=\sum_{k=1}^{n}\langle u,e_k\rangle e_k. ]

由于 (\varphi) 是线性泛函，

[ \begin{aligned} \varphi(u) &=\varphi\left(\sum_{k=1}^{n} \langle u,e_k\rangle e_k\right)\ &=\sum_{k=1}^{n} \langle u,e_k\rangle\varphi(e_k). \end{aligned} ]

现在定义向量

[ \boxed{ v=\sum_{k=1}^{n}\overline{\varphi(e_k)}e_k }. ]

由于内积对第二个位置共轭线性，

[ \begin{aligned} \langle u,v\rangle &=\left\langle u,\sum_{k=1}^{n}\overline{\varphi(e_k)}e_k \right\rangle\ &=\sum_{k=1}^{n} \varphi(e_k)\langle u,e_k\rangle\ &=\varphi(u). \end{aligned} ]

因此，存在向量 (v)，使得对所有 (u\in V) 都有

[ \varphi(u)=\langle u,v\rangle. ]

接下来证明唯一性。

假设还有另一个向量 (w)，满足

[ \varphi(u)=\langle u,w\rangle ]

对所有 (u\in V) 都成立。那么

[ \langle u,v\rangle=\langle u,w\rangle, ]

所以

[ \langle u,v-w\rangle=0 ]

对所有 (u\in V) 成立。取 (u=v-w)，得到

[ |v-w|^2=0. ]

因此 (v=w)，唯一性得证。
