going to data science and visualise data

Types of Question:

  1. Descriptive: summarize a characteristic of a set of data
  2. Exploratory: analyse to see if there are patterns, trends, or relationships between variables (hypothesis generating)
  3. Inferential: analyse patterns, trends, or relationships in representative data from a population
  4. Predictive: make predictions for individuals or groups of individuals
  5. Causal: whether changing one factor will change another factor, on average, in a population
  6. Mechanistic: explore "how" as opposed to whether

scientific studies:

observational:

Collect data in a way that does not interfere with how the data arise ("observe")

Establish associations/correlation

experimental:

Randomly assign subjects to treatments

Establish causal connection

Visualize

1. 基础绘图与映射

函数 / 写法 作用 什么时候用 示例
ggplot() 创建图形 开始画图、指定数据集 ggplot(data =[data set])
aes() 将变量映射到图形属性 想让数据决定位置、颜色、大小等 aes(x = , y = )
x、y 指定横轴、纵轴 想展示两个变量的关系 aes(x = , y = )
colour / color 映射或设置颜色 区分不同类别或数值 aes(colour = class)
fill 设置图形内部填充色 区分柱子、箱体等的内部颜色 aes(fill = class)
size 控制大小 用点的大小表达变量 aes(size = displ)
shape 控制点的形状 用点形区分类别 aes(shape = class)
alpha 控制透明度 减轻重叠，或表达变量 aes(alpha = class)

特别注意： aes(colour = class) 是让颜色随 class 变化；colour = "blue" 则是把图形固定为蓝色。前者写在 aes() 内，后者写在外面。

2. Geom：选择用什么图形展示数据

函数 画什么 什么时候用 关键区别
geom_point() 散点图 查看两个数值变量的关系 每个点通常代表一条观测
geom_smooth() 平滑趋势线 观察变量间的总体趋势 展示拟合趋势，而不是每条原始观测
geom_bar() 柱状图 统计各类别出现多少次 默认自动计数
geom_col() 柱状图 已经有每个类别对应的数值 直接使用提供的 y
geom_boxplot() 箱线图 比较不同类别的数据分布 查看中位数、四分位数及异常值等
geom_histogram() 直方图 查看连续数值的分布 将数值分组后统计频数
geom_line() 折线图 展示有顺序的数据变化 常用于时间或有序序列
geom_jitter() 带抖动的散点图 很多点重叠时 给点的位置加入小幅随机扰动
geom_count() 按重叠数量调整大小的点图 相同坐标上有大量重复观测时 点越大，通常表示该位置观测越多
geom_abline() 直线 添加参考线 默认斜率为 1、截距为 0

3. Facets：分面

函数 作用 什么时候用 示例
facet_wrap() 按一个变量拆成多个子图 想分别查看每个类别 facet_wrap(~ class)
facet_grid() 按行变量和列变量组织子图 想同时比较两个分类变量 facet_grid(drv ~ cyl)
nrow 指定分面布局的行数 想控制子图排布 facet_wrap(~ class, nrow = 2)
ncol 指定分面布局的列数 想控制子图排布 facet_wrap(~ class, ncol = 3)

分面适合类别较多、需要分别观察各组规律的情况。facet_wrap() 通常用于一个变量；facet_grid() 用于行和列两个变量。

4. Stat：统计变换

函数 / 参数 作用 什么时候用
stat_count() 计算每个类别的数量 需要明确使用计数统计时
stat_summary() 对每个 x 类别的 y 值进行汇总 想画中位数、最小值、最大值等摘要
stat_smooth() 计算平滑趋势 想明确使用统计变换来绘制趋势
after_stat(prop) 引用统计计算得到的比例 柱状图展示比例而不是数量时
stat = "identity" 不重新计算数量，直接使用数据中的值 柱子的高度已经存在于数据中
group = 1 把数据指定为一个统计分组 某些总体比例计算中，避免按默认分组分别计算 
  geom_bar(
    aes(x = cut, y = freq),
    stat = "identity"
  )

5. Position：位置调整

参数 作用 什么时候用
"stack" 堆叠图形 比较各类别的总数量及组成
"dodge" 并排显示图形 直接比较不同组的数量
"fill" 将堆叠柱子标准化为相同高度 比较各组内部的比例
"identity" 在原始位置绘制，不进行位置调整 想让图形重叠显示；柱状图可能会互相遮挡
geom_jitter() 对点的位置添加抖动 许多观测重叠时
geom_count() 通过点的大小表示重复观测数量 想知道相同坐标上有多少条观测 
  geom_bar(position = "fill")

6. Coordinate：坐标系统

函数 作用 典型用途
coord_flip() 交换 x、y 轴 类别名称很长，或者想画横向箱线图
coord_quickmap() 设置适合地图的纵横比例 绘制地理空间数据
coord_map() 使用地图投影 需要地图投影时；具体差异可查函数帮助
coord_polar() 转换到极坐标 把柱状图转换为饼图等极坐标图
coord_fixed() 固定 x、y 单位的物理比例 比较两个数值轴时，避免视觉比例误导

辅助函数：

函数 作用 什么时候用
labs() 设置标题、轴标签等 想修改图形文字
theme() 控制图形的主题与部分布局样式 想调整外观，例如纵横比例

7.综合图层写法

ggplot(data = mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  geom_smooth(
    data = filter(mpg, class == "suv"),
    se = FALSE
  ) +
  facet_wrap(~ class)
