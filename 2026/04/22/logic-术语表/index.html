Logic Core Terms (Ch.1–3)

1. Syntax and Semantics

Syntax 表达式的形式规则，决定是否写得合法。

Semantics 表达式的意义与真值。

Well-formed formula (WFF) 符合语法规则的表达式。

2. Sentence Structure

Atomic sentence 不含联结词的基本句子。

Molecular sentence 由联结词构成的复合句。

Connectives 逻辑联结词：否定、合取、析取、条件、双条件。

Truth value 句子的真假。

Truth table 列出所有可能真值组合的表。

3. Logical Status

Tautology 在所有情况下都为真。

Contradiction 在所有情况下都为假。

Contingent sentence 有时真、有时假。

Logical equivalence 两个句子在所有情况下真值相同。

Logical truth 仅由形式保证为真。

4. Arguments and Inference

Argument 由前提和结论构成的推理。

Premise 支持结论的陈述。

Conclusion 推理得到的陈述。

Validity 若前提为真，则结论必为真。

Invalidity 存在前提真但结论假的情况。

Derivation 形式化证明过程。

5. Predicate Logic Basics

Predicate 表示性质或关系的符号。

Variable 表示任意对象的符号。

Atomic formula 谓词加一个项构成的公式。

Formula 符合语法规则的表达式。

Sentence 不含自由变量的公式。

Free variable 未被量词绑定的变量。

Bound variable 被量词控制的变量。

6. Quantifiers

Quantifier 表示范围的符号（全称或存在）。

Scope 量词所控制的部分。

Binding 量词对变量的控制关系。

Interpretation 符号与对象之间的对应。
