SVD拓展

本部分就只是一些svd的使用场景，主要是 image compression 和 latent semantic indexing。

图像压缩（image compression）

据估计，目前互联网上多达90%的数据是在过去几年间产生的。每天，数百万张图片被发布到不同的网站上，数万小时的视频被流式传输和上传。正是得益于数据压缩，如此庞大的信息量才能得以持续传输。研究人员开发了多种数据压缩应用，旨在在大幅减少存储或传输信息量的同时，尽可能保留 原始数据的真实近似。在此，我们将探讨一种利用svd基本压缩技术。

原理

每幅图像都可以表示为一个矩阵。 图像中每个像素的颜色都会被分配一个数值，该数值存储在 矩阵的相应元素中。

我们可以使用svd去简化数据。在先前的svd学习中，我们知道任何一个svd矩阵都可以写成 $$ A = \sigma_1 u_1 v_1^T + \sigma_2 u_2 v_2^T + \cdots + \sigma_r u_r v_r^T $$ 而且因为我们事先知道singular value 是从大到小排列的，所以权重较大的部分都会在前面。 所以对于一张图，我们加的项越多，所得到的图像中的细节就越多。

例子

以下是一串python代码，可以使用vscode查看。

import numpy as np
import matplotlib.pyplot as plt
from PIL import Image

#读取图像并转为灰度
img = Image.open(".jpg").convert("L")  # 灰度图，记得改图片名称
A = np.array(img, dtype=float)

#SVD 分解
U, S, Vt = np.linalg.svd(A, full_matrices=False)

#重建函数（截断 SVD）
def reconstruct(k):
    return U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]

#不同 k 值对比，（可更改）
ks = [5, 20, 50, 100]

plt.figure(figsize=(10, 8))

for i, k in enumerate(ks):
    plt.subplot(2, 2, i+1)
    Ak = reconstruct(k)
    plt.imshow(Ak, cmap='gray')
    plt.title(f"k = {k}")
    plt.axis('off')

plt.tight_layout()
plt.show()

你可能就会看到这样的图片，我们会发现k越大时，图像越清晰，而这个k就是前k项之和。

这就是svd在图像上的运用。

潜在语义索引（Latent Semantic Indexing）

在文本数据中，我们通常使用 term-document matrix（词-文档矩阵） 来表示文档：

  • 每一行：一个单词
  • 每一列：一个文档
  • 每个元素：词频

然而，这种表示存在问题：

  • 同义词（car / automobile）无法识别
  • 噪声较多
  • 维度很高

所以我们希望提取“隐藏的语义结构”

原理

LSI 的核心是对矩阵进行 SVD 分解： $$ A = U \Sigma V^T $$

  • 大奇异值 → 重要语义
  • 小奇异值 → 噪声

只保留前 $k$ 个奇异值： $$ A_k = \sum_{i=1}^{k} \sigma_i u_i v_i^T $$

例子

我们构造一个简单的 term-document matrix： $$ A = \begin{bmatrix} 1 & 0 & 1 \ 1 & 1 & 0 \ 0 & 1 & 1 \end{bmatrix} $$

Python Code

import numpy as np

# 构造 term-document matrix
A = np.array([
    [1, 0, 1],
    [1, 1, 0],
    [0, 1, 1]
], dtype=float)

# SVD 分解
U, S, Vt = np.linalg.svd(A, full_matrices=False)

print("U =\n", U)
print("S =\n", S)
print("V^T =\n", Vt)

# 截断（k=2）
k = 2
Uk = U[:, :k]
Sk = np.diag(S[:k])
Vk = Vt[:k, :]

Ak = Uk @ Sk @ Vk

print("\nReduced Matrix A_k =\n", Ak)

相似词会更接近 文档结构更清晰
